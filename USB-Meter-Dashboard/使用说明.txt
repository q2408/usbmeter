USB Meter Dashboard 使用说明
=====================

1. 双击 start.bat 启动（默认不会自动打开浏览器）。
   启动后会额外弹出一个「USB Meter Dashboard - 实时读数」CMD 窗口。
2. 需要网页时，按窗口里打印的地址打开：
       本机:   http://127.0.0.1:8765/
       局域网: http://<这台电脑的IP>:8765/
3. 用 USB-C 数据线把仪表接到电脑，1 秒内自动连上。

实时纹波（100 sps 交流分析）
----------------------------
网页曲线切到「纹波」标签：去掉最近 2 秒的直流基线，只画交流波动（mV，带 0 轴），
右侧显示 纹波 Vpp（峰峰值）和 纹波 Vrms（有效值）；控制台窗口也会多一行。
注意：USB 只送 100 sps，只能反映 ≤50 Hz 的波动；开关电源高频纹波请用仪表自带的
「高速纹波（AC 耦合，最高 3.2 Msps）」模式，那个波形只在表屏幕上，PC 拿不到。

实时读数窗口
------------
- 每 0.5 秒刷新，只读服务接口，关掉它不影响记录
- 主程序关闭后，这个读数窗口会在几秒内自动退出
- 不想弹：start.bat --no-console
- 想在另一台电脑上看：
      runtime\python.exe tools\live.py --url http://<这台电脑的IP>:8765

记录与平滑
----------
- 默认不写文件，只显示实时图表；点网页右侧「未记录（点击开始）」才开始写 CSV
- 记录文件固定在本文件夹的 logs\ 里，不会写到 C 盘别处
- 曲线时间窗最长 30 分钟（10s / 30s / 1m / 5m / 10m / 30m）
- 设置（右上角齿轮）里可以调「仪表平滑」：关 / 弱(0.3s) / 中(1s) / 强(3s) / 更强(5s) / 极强(10s)，
  只影响页面大数字和控制台，曲线和 CSV 仍是原始数据

出问题先看诊断页面
------------------
    http://127.0.0.1:8765/debug
- 「HID 设备」里应该能看到仪表
- 「事件日志」会记录打开设备、发送命令、收首包、超时、重连
- 点右上角「复制诊断信息」或「下载 JSON」可保存当前快照
- 设置里可开「隐私模式」：SN / VID:PID / 路径打码，其他 HID 设备隐藏；默认关闭，不影响连接

设备假死（系统里还能看到它，但序列号读不出、写入失败）
----------------------------------------------------------
只能拔插一次 USB 线。禁用/启用、pnputil 重启等软件重置实测无效，
反而会让设备从系统里消失，所以程序不再自动重置。
另外不要频繁点「断开设备 / 重新扫描」，正常连着就好。

Windows 提示 USB 不可用 / 已禁用
--------------------------------
先拔插一次；仍不行打开设备管理器：
  Win+X -> 设备管理器 -> 查看 -> 显示隐藏的设备
  在「人机接口设备」里找带黄色感叹号的设备，右键「启用设备」；
  或「卸载设备」后点「操作 -> 扫描检测硬件改动」

改端口（网页里）
----------------
设置 -> 服务端口：填 1024-65535，保存后页面会自动跳到新地址，旧地址失效。
端口会记在 config.json 里，下次启动沿用；也可以在命令行用 --port 指定。

局域网访问
----------
默认监听所有网卡，同一局域网的手机 / 平板 / 其他电脑可以打开：
    http://<这台电脑的IP>:8765/
启动窗口会打印可用的局域网地址，选和对方同网段的那个。
第一次运行如弹出 Windows 防火墙提示，请勾选「专用网络」并允许。

注意：没有登录和密码，能访问这个端口的人都能看数据、下载 CSV、改设置。
只在可信网络里用，不要映射到公网。
只想本机使用：start.bat --host 127.0.0.1

拷贝到别的电脑
--------------
这是绿色便携版：把整个 USB-Meter-Dashboard 文件夹一起压缩带走，解压后双击 start.bat 即可。
目标电脑不需要装 Python，也不需要装驱动（要求 64 位 Windows 10/11）。
不要只拷 start.bat；也不要放在 C:\Program Files 这类不可写目录。

文件说明
--------
start.bat          双击启动
logs\              每次测量自动生成的 CSV 记录
config.json        报警阈值、温度单位、时间窗等设置
docs\protocol.md   USB HID 协议逆向笔记
runtime\           内置 Python 3.14 运行时（免安装的关键）
vendor\            hidapi 模块
web\               界面文件（含 /debug 诊断页）
tools\live.py      实时读数窗口
tools\dump.py      原始数据抓取

排错
----
找不到设备：先关掉官方上位机，再换一根数据线 / 换一个 USB 口。
连上了但没数字：打开诊断页看事件日志；连续失败时拔插一次 USB。
仍不行：运行 runtime\python.exe tools\dump.py 抓取原始数据（存到 logs\raw-*.bin）。
